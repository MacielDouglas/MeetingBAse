# Regras Globais do Projeto — Meeting Base

1. **Idioma:** Responda SEMPRE em português do Brasil (pt-BR). UI do app em espanhol (es). Código e comentários em espanhol ou inglês simples.
2. **Acesso proibido:** NUNCA acesse, leia, escreva ou liste arquivos em `C:\*` / `C:` e NUNCA acesse arquivos `.env` (incluindo `.env.*`, `.env.local`, etc.) em qualquer diretório.
3. **Arquivos temporários:** Use SEMPRE `D:\temp` para criar, escrever ou manipular arquivos temporários.
4. **Tamanho máximo:** Nenhum arquivo de código com mais de 400 linhas. Se passar, divida em mais componentes / módulos.
5. **Referência:** Consulte `D:\TheocBase` e `D:\TheocBase\jwpub` como referência de domínio quando precisar. Só leitura.
6. **Decisões:** Pergunte ao usuário tudo que tiver que ser decidido. Não assuma regras de negócio.
7. **Multiplataforma:** Este React Native é iOS e Android (Expo + EAS). Toda feature precisa funcionar nas duas plataformas.

Estas regras valem para TODAS as sessões deste projeto e têm prioridade máxima.
